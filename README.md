# Walmart Sales Analysis

## Project Overview
This project analyzes Walmart sales data to understand store performance and the impact of external factors such as holidays, temperature, fuel prices, CPI, and unemployment.

## Dataset
Columns:
- Store
- Date
- Weekly_Sales
- Holiday_Flag
- Temperature
- Fuel_Price
- CPI
- Unemployment

## SQL Skills Demonstrated
- Aggregations
- GROUP BY
- CASE WHEN
- CTEs
- Window Functions
- RANK()
- LAG()
- Running Totals
- Moving Averages

## Business Questions Answered
1. Which stores generate the highest revenue?
2. What percentage of total sales does each store contribute?
3. How do holidays impact sales?
4. What are the sales trends over time?
5. Which stores show the most consistent performance?
6. How does unemployment affect sales?

## Key Insights
- Top-performing stores contribute a significant share of total revenue.
- Holiday periods generally show stronger sales performance.
- Some stores exhibit high sales volatility.
- Economic indicators appear to influence sales patterns.
